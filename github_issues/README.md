## 2. Instrucciones para Publicación en GitHub

Para cargar estos issues directamente al repositorio de GitHub:
1. Abrir la pestaña **Issues** en el repositorio remoto.
2. Hacer clic en **New issue**.
3. Copiar el título y contenido markdown de cada archivo individual `ISSUE_0X_...`.
4. Asignar el colaborador correspondiente y aplicar las etiquetas (*labels*) sugeridas.
